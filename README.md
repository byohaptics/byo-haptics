# BYO Haptics

BYO Haptics samples avatar haptic sensations and routes normalized values to a replaceable output plugin.

This repository contains the host tool, the public plugin contract, a Joy-Con OSC plugin, and a Haptira OSC plugin. The first milestone is feature parity with the private prototype while rebuilding from public specifications.

## Status

Version `0.1.0` is under reconstruction and is not a release.
